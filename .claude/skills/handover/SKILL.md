# /handover

1. 読む: 判断ログ（前回の handover 更新以降の項目）、各ラウンドの台帳、最新の結果文書、`project.yaml`。
2. `docs/handover.md` を更新する（このファイルは追記専用ではない）。
   - 状態表: データセット、プロトコル、標準モデル（判断ログ番号つき）、進行中ラウンド、テスト件数。
   - 見出しの結果: 推定値・ばらつき・区間を分けて書き、結果文書へのリンクを付ける。数値は結果文書から写し、`tools/verify_doc_numbers.py` で照合できる注釈を付ける。
   - 固有の規則: 新しく増えた「破ってはいけないこと」（例: バージョン間で並べてよい数値の条件）。
   - 置き場所・動かし方: git 外の場所（project.yaml の paths）とコマンド。
   - 残作業: 台帳の `保留` `候補` と、その再開条件。
3. テストを実行して件数を確かめる。
4. 最終更新日を書き換え、コミット: `Handover: <要点>`
5. 引き継ぎ先が人なら、最初に読む順番（handover → 判断ログ 0001 から → 台帳）をユーザーへの返答に書く。
