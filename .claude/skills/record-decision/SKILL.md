# /record-decision

1. 判断ログの最後の項目番号を読み、次の番号（4桁）を決める。番号の重複に気づいても既存の番号は直さず、新しい項目に注記する。
2. 次の書式で**末尾に**追記する（Edit で最後の行を old_string にし、その後ろに足す。hook が書き換えを止める）。

```markdown

## NNNN — YYYY-MM-DD — 短い題名（ABC-NN）

### 決めたこと
1. 

### 理由
（根拠となる結果文書・プロトコル・ユーザーの発言へのリンク）

### 無効にするもの
- （過去の判断を覆すなら番号と、どの部分か。なければ「なし」）

### 約束すること
- 
```

3. 書くときの注意:
   - 結果を見た後の判断なら、そう書く。同じデータで判断を重ねた場合はそれも書く。
   - ユーザーや指導教員が決めたことは、誰がいつ決めたかを書く。
   - 数値を書くなら、出どころのファイルへのリンクを付け、元ファイルで確かめてから書く。
4. 同じ判断を、該当ラウンドの progress と Linear Issue の「決定」欄にも1行で反映する。必要なら `docs/handover.md` の状態表も更新する。
5. コミット: `Decision NNNN: <題名> (ABC-NN)`
