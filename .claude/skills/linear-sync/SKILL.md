# /linear-sync

対応表と書式は docs/linear.md にある。チーム・プロジェクトは project.yaml の `linear`。

## 1. 集める

- 進行中ラウンドの台帳の全行（ID、作業、状態、証拠列の Issue 番号）
- progress の末尾数件
- Linear: プロジェクトの Issue 一覧（状態、ラベル、更新日、親子関係）

## 2. 突き合わせる

次のずれを一覧にする。

| 種類 | 直し方 |
|---|---|
| 台帳の行に Issue が無い | Issue を作り、番号を台帳に書く |
| Issue が台帳に無い | ユーザーに確認し、台帳に `候補` で足すか、Issue を Canceled |
| 状態が対応表とずれている | 新しいほうの記録（progress の日付、コミット）に合わせる |
| 完了なのに証拠リンクが無い | 証拠を探して台帳に入れる。見つからなければ完了にしない |
| 中止・保留なのに理由が無い | progress に理由を追記してから状態を変える |

判断に迷うもの（どちらが正しいか分からない状態）は変更せず、ユーザーに聞く。

## 3. 直す

- Linear の状態変更・コメント・Issue 作成を行う（削除はしない）。
- 台帳を更新する。progress には「台帳と Linear を同期」と変更点を追記する。
- コミット: `Sync ledger with Linear (<round>)`

## 4. 報告

ユーザーには、進行中・次にやる・止まっているもの（理由つき）を短い表で返す。
