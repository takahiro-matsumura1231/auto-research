## このページの使い方

1. [議論と出発点](context.md)で、受けた質問、回答済みのこと、未検証の主張を確認する。
2. [実行計画](plan.md)の順番と、各段階を終える条件を確認する。
3. 下の台帳の次の項目を進め、着手・完了のたびに状態、日付、証拠のリンクを更新する。
4. 学習を伴う実験は、**実行前**にプロトコル（`docs/protocols/`）と判断ログの新しい項目で、仮説・比較・予算・解析方法を凍結する（`/preregister`）。
5. 判断の変更は既存の記録を書き換えず、[進捗ログ](progress.md)に日付付きで追記する。

状態: `候補` / `未着手` / `調査中` / `設計中` / `登録済` / `実行中` / `分析中` / `完了` / `保留` / `中止`。候補は、登録済になるまで実施の決定ではない。
