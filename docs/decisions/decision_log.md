# Decision log

追記専用。新しい項目は末尾に足す。過去の項目は編集・削除・番号の振り直しをしない。間違いだった判断は、後の項目で「何を無効にするか」を書いて上書きする（hook で保護している）。

各項目に書くこと: **決めたこと**、**理由**、**無効にするもの**、**約束すること**。関係する Linear Issue とプロトコルへのリンクも書く。

書式:

```markdown
## NNNN — YYYY-MM-DD — 短い題名（ABC-12）

### 決めたこと
1. ...

### 理由
...

### 無効にするもの
- ...（なければ「なし」）

### 約束すること
- ...
```
